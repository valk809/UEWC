FAIR PLAY • DISCIPLINE • COMPETITION

In-Game Rules

01 • GAMEPLAY VIOLATIONS

Using GK TP: -1
Saving a shot using GK TP: -2
Using double shots: -1
Scoring with double shots: -2
Using pass button / lob shots: -1
Scoring using pass button / lob shots: -2
Tackling goalkeeper inside box: -1
Tackling goalkeeper and causing a goal: -2
Blocking goalkeeper inside box: -1
Using Awakening inside opponent's box: -1
Abusing bugs or glitches: -1

02 • DELAY POLICY

Each team is allowed a 20-minute delay or a 1-day delay.
Maximum 2 delays per match.
If a team is 20 minutes late, it receives FFT.

03 • FFT STAT ALLOCATION

Goals: 3 • Assists: 3 • Tackles: 7 • Saves: 5

04 • RECORDING & AFK

Failure to provide recording: -2
AFK for 25 seconds: -1
Players must leave the match if AFK.
Faking AFK: -2.

05 • MATCH ETIQUETTE

Asking for a pause by saying Sorry then continuing to play: -2.
Players must say Nice and allow everyone to get into position before restarting.
Stealing kickoff or starting from opponent's half: -1.

06 • MATCH STATISTICS

Screenshots of match stats must be taken after every match. Without screenshots, no players receive match statistics.
