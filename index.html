UEWC • Official regulations

In-game rulebook.

Fair play, discipline and competition are expected from every team.

01Gameplay Violations

  • Using GK TP −1
  • Saving a shot using GK TP −2
  • Using double shots −1
  • Scoring with double shots −2
  • Using the pass button / lob shots −1
  • Scoring using the pass button / lob shots −2
  • Tackling the goalkeeper inside the box −1
  • Tackling the goalkeeper and causing an goal inside the box −2
  • Blocking the goalkeeper inside the box −1
  • Using Awakening inside the opponent's box −1
  • Abusing bugs or glitches −1

02Delay Policy

Each team is allowed to request a 20-minute delay or a 1-day delay.

A maximum of 2 delays per match is permitted.

If a team is 20 minutes late, it will receive an FFT (Forfeit).

03FFT Stat Allocation

  • Goals 3
  • Assists 3
  • Tackles 7
  • Saves 5

04Recording & AFK Policy

Failure to provide a recording: −2

Being AFK for 25 seconds: −1

Players must leave the match if they are AFK.

Faking AFK: −2

05Match Etiquette

Asking for a pause by saying "Sorry" and then continuing to play: −2

Players must say "Nice" and allow everyone to get into their respective positions before restarting play.

Stealing the kick-off or starting the kick-off from the opponent's half: −1

06Match Statistics

Screenshots of the match statistics must be taken after every match.

Without a screenshot, no players will receive match statistics.
