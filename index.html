In-Game Rules

01 • Gameplay violations
Using GK TP: -1
Saving a shot using GK TP: -2
Using double shots: -1
Scoring with double shots: -2
Using the pass button / lob shots: -1
Scoring using the pass button / lob shots: -2
Tackling the goalkeeper inside the box: -1
Tackling the goalkeeper and causing an goal inside the box: -2
Blocking the goalkeeper inside the box: -1
Using Awakening inside the opponent's box: -1
Abusing bugs or glitches: -1
02 • Delay policy
Each team is allowed a 20-minute delay or a 1-day delay.
Maximum 2 delays per match.
If a team is 20 minutes late, it receives FFT (Forfeit).
03 • FFT stat allocation
Goals: 3 • Assists: 3 • Tackles: 7 • Saves: 5
04 • Recording & AFK
Failure to provide a recording: -2
AFK for 25 seconds: -1
Players must leave the match if AFK.
Faking AFK: -2.
05 • Match etiquette
Asking for a pause by saying “Sorry” then continuing to play: -2
Players must say “Nice” and allow everyone to get into respective positions before restarting.
Stealing kickoff or starting from opponent's half: -1.
06 • Match statistics
Screenshots of match stats must be taken after every match.
Without screenshot, no players receive match statistics.
